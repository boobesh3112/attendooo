🎯 WHAT TO DO IF SOMETHING BREAKS
═══════════════════════════════════════════════════════════════════════

If buttons don't work:
1. Check browser console for errors
2. Verify CSS fix is present in glassmorphism.css
3. Check for z-index issues
4. Verify pointer-events: none on pseudo-elements

If routing doesn't work:
1. Check vercel.json/netlify.toml exists
2. Verify rewrite/redirect rules
3. Check base path configuration
4. Test with browser's dev tools

If assets don't load:
1. Check network tab for 404s
2. Verify build output directory
3. Check asset paths in code
4. Verify Vite build completed successfully

If mobile doesn't work:
1. Check touch event handlers
2. Verify touch target sizes
3. Check viewport meta tag
4. Test with Chrome DevTools mobile emulator
